以下正文提供具体的数据类型、用途和处理方式。

1. 适用范围与责任主体

Monsoon Isle（“我们”）是 The Arrow 的开发者，负责本政策所述由我们决定目的和方式的信息处理活动。本政策适用于 The Arrow Android 游戏（包名：com.monsoonisle.thearrow）、相关支持通信，以及第 11 节所述的 Monsoon Isle 网站。

个人信息包括能够直接识别你，或与其他信息结合后识别你的信息。设备标识符、安装标识符和 IP 地址也可能属于个人信息，即使它们不包含你的真实姓名。

2. 本地信息与主动提供的信息

设备上的游戏记录

游戏在设备上保存设置、关卡进度、成就、每日奖励、未完成对局及诊断记录，用于恢复游戏状态和运行相关功能。本地统计记录还包含游戏事件及随机生成的安装、会话和事件标识符。

本地保存并不意味着所有相关信息都只在设备上处理。部分进度、对局和广告事件会通过第 3 节所述的统计服务发送；这与上传完整存档或提供云存档服务不同。

你主动提供的信息

你通过邮件联系我们时，我们会收到你的邮箱地址、消息及你自愿提供的附件，用于回复、排查问题和处理申请。请只提供必要的信息，避免发送密码、支付资料或不必要的敏感信息。

游戏无需玩家账号，也不要求提供姓名或联系方式。当前游戏不请求精确位置、通讯录、相机或麦克风权限。

3. 游戏使用统计

The Arrow 使用 Google Analytics for Firebase 了解游戏使用情况、调整玩法和排查问题。启用统计的版本会向 Google 发送：

  • 游戏与广告活动：启动与会话时长、关卡开始和结果、进度变化、教程、提示与奖励使用、广告请求、展示及点击。
  • 技术信息：事件时间、游戏版本、设备型号、操作系统、语言、加载时长及技术错误。
  • 标识符：随机生成的安装、会话和事件标识符；Google SDK 还可能处理应用实例标识符及大致地理信息。

我们通过该服务查看和分析统计数据。随机标识符可关联同一次安装或会话的事件，因此这些信息不能一概视为完全匿名。

当前 Firebase 配置关闭了统计服务的广告 ID 收集和广告个性化信号。这项设置仅针对 Analytics，不会关闭 AdMob 的独立数据处理。

4. 广告服务

The Arrow 使用 Google AdMob 提供激励广告和插屏广告。你可以选择观看激励广告以获得相应游戏奖励。

为投放和衡量广告、防止欺诈，Google 移动广告 SDK 会处理 IP 地址及其推断的大致位置、应用与广告交互、性能等诊断信息，以及广告 ID、应用集 ID 等设备或账号标识符。具体处理受 SDK 版本、配置、设备设置和适用的同意状态影响。应用集 ID 用于分析、防欺诈等允许的用途，不用于广告个性化。

广告是否个性化取决于适用的同意状态、广告配置和设备设置。非个性化广告仍可能涉及投放、频次控制、安全和统计所需的数据处理。选择观看激励广告本身，不等于同意与提供奖励无关的跟踪或个性化广告。

详情见 Google 隐私政策及 Google 移动广告 SDK 数据披露。你的可用选择见第 8 节。

5. 处理目的与依据

我们为以下目的处理上述信息：运行和保存游戏功能；了解玩法表现并修复问题；提供和衡量广告、发放奖励并防止滥用；回复支持及隐私请求；履行适用法律义务。

在适用法律要求明确处理依据的地区，提供你请求的游戏功能和支持所必需的处理，以履行相关服务约定为依据；依法必须保留或披露的信息，以履行法律义务为依据。在法律允许且不优先于你的权利和利益时，维护安全、排查故障和改进服务可以基于相应的合法利益。

依法需要同意的统计、设备信息访问或个性化广告处理，应在获得有效同意后进行；合法利益不能替代依法必须取得的同意。你可以按第 8 节申请撤回同意。阅读本政策或继续使用游戏本身，不构成对这些处理的同意。

6. 信息共享与跨境处理

  • Google：通过 Firebase Analytics 和 AdMob 接收第 3、4 节所述信息，按各服务适用的条款和隐私说明处理。
  • 托管与通信服务提供商：GitHub Pages 托管网站，邮件服务提供商处理支持消息；各自涉及其功能所需的信息。
  • 法律与安全需要：如为遵守适用法律、回应合法请求或保护用户与服务安全而确有必要，我们可能披露相关信息，并将范围限于合理必要的程度。
  • 你的指示或同意：如需为其他目的共享个人信息，我们会在法律要求时另行告知并取得同意。

我们不出售你的本地游戏存档。广告服务中的数据传输可能被某些地区的法律认定为个人信息的“出售”“共享”或定向广告处理；“不出售存档”不代表不存在这类活动。相关权利见第 8 节。

服务提供商可能在你所在国家或地区以外（包括美国）处理信息，相关地区的数据保护规则可能不同。需要跨境保护措施时，应按适用法律采用相应的传输机制和保障措施。你可通过服务提供商的隐私说明了解其处理地点和保障，也可联系我们咨询与我们处理活动有关的信息。

7. 信息保留与删除

我们使用 Google 提供的统计和广告服务，不在自建服务器另行保存游戏统计原始数据。设备上的本地记录、Google 托管的数据和你发送的支持邮件仍分别适用以下保留规则：

  • 本地存档与统计记录：游戏会在设备上保存进度、设置及本地统计记录，保留至被更新、覆盖或删除。可在 Android 设置中清除 The Arrow 的应用存储，或卸载游戏以删除本地数据；这会重置进度。设备迁移或备份服务可能另有副本，需要通过对应服务管理。
  • Firebase Analytics 统计数据：由 Google 托管。我们对适用的用户级和事件级统计数据采用 2 个月的保留政策，到期数据由 Google 按其定期删除流程清理。该期限不适用于标准汇总报告、AdMob 广告数据或设备上的本地记录。详见 Google Analytics 数据保留说明。
  • AdMob 广告数据：由 Google 按广告投放、衡量、防欺诈等用途、适用政策和法律要求保留。不同数据的期限可能不同，不能套用 Analytics 的保留设置。详见 Google 数据保留说明。
  • 网站托管日志：由 GitHub 按托管服务用途、隐私声明及适用法律保留。
  • 支持通信：仅在处理问题、跟进请求及履行适用法律义务所需期间保留，不再需要时删除或匿名化。

清除应用存储、卸载游戏或删除广告 ID，不会自动删除此前已发送给 Google 的数据。申请访问或删除我们能够识别和控制的信息，请按第 8 节联系我们。对依法需要继续保留的信息，我们会说明原因及适用限制。

8. 你的选择与隐私权利

设备和广告选择

你可以在 Android 或 Google 设置中管理可用的广告隐私选项，包括重置或删除广告 ID；入口因设备和系统版本而异。这些操作不会关闭所有统计或广告数据处理，也不等同于删除已收集的数据。

当前游戏没有应用内统计关闭开关。若希望撤回同意、反对相关处理或了解可用的限制方式，请通过下方邮箱联系我们。邮件申请不等于设备上的 SDK 已即时停止运行；如需立即停止该安装继续产生游戏事件，可停止使用并卸载游戏。

提出隐私请求

依所在地的适用法律，你可能有权知悉和访问个人信息、取得副本、更正或删除信息、限制或反对处理、请求数据可携带，以及撤回同意。撤回不影响此前基于同意进行的合法处理。部分地区还赋予定向广告及个人信息“出售”或“共享”的退出权、申诉权，以及向有管辖权的监管机构投诉的权利。

欧洲经济区、英国及瑞士用户可依适用法律行使上述数据保护权利，并向所在地有管辖权的数据保护机构投诉。美国居民可在适用州法律赋予权利的范围内申请退出个人信息的“出售”“共享”或定向广告处理。东南亚及其他地区用户可依所在地适用法律提出请求；本政策不限制当地法律赋予的权利。

请发送邮件至 aquark314@gmail.com，注明“The Arrow 隐私请求”，说明希望采取的操作，以及有助于定位记录的版本、使用时间等信息。我们仅在核实申请、保护数据或定位记录所需的范围内请求补充信息；请勿主动发送身份证件或密码。

游戏没有账号系统，仅凭姓名或邮箱通常无法关联所有安装或 SDK 记录。如果无法定位数据，或信息由服务提供商独立控制，我们会解释限制，并在可行时提供相关申请途径。我们将按适用法律规定的期限处理；如需延长或无法满足，会说明原因和适用的后续途径。我们不会因你依法行使隐私权利而给予不公平待遇。

9. 儿童与未成年人隐私

The Arrow 面向 13 岁及以上用户，不以 13 岁以下儿童为目标受众。应用商店的内容分级（例如“3+”）描述内容适宜性，与本游戏的目标受众和隐私同意要求不同。

13 岁及以上用户仍可能属于当地法律保护的未成年人。若所在地对数据处理、监护人同意或个性化广告规定了更高年龄门槛或其他保护要求，这些要求仍然适用；达到 13 岁或商店内容分级本身不能替代所需同意。家长或监护人应结合本政策管理未成年人的使用。

游戏包含第三方广告和统计功能，第 3、4 节所述技术数据可能被处理。我们不在游戏中要求提供姓名或联系方式，但这不表示不会处理未成年人的个人信息。

如果你认为 13 岁以下儿童的信息已通过本游戏被收集，或我们在缺少法律要求的同意或保护措施时处理了未成年人个人信息，请通过 aquark314@gmail.com 联系我们。核实后，我们会删除能够识别和控制的相关信息、限制相关处理，并在需要时协助向服务提供商提出请求。

10. 信息安全

我们采取与信息性质及处理风险相适应的合理保护措施。Google 的相关 SDK 使用加密连接传输数据；本地记录也依赖设备及操作系统的访问保护。任何存储或传输方式都无法保证绝对安全。

请妥善保护设备，并仅通过指定联系渠道提交必要的支持信息。发生依法需要通知的信息安全事件时，我们会按适用要求履行通知义务。

11. 网站访问与外部链接

Monsoon Isle 网站（monsoonisle.github.io）用于介绍游戏、展示本政策和提供联系方式。目前页面不加入广告或访问统计脚本，不设置用于跟踪的 Cookie，也不使用浏览器本地存储记住语言；显示语言由访问的网址决定。

网站由 GitHub Pages 托管。访问时，GitHub 会为安全目的记录访问者的 IP 地址，相关处理受 GitHub 隐私声明约束。网站没有自行部署统计脚本，并不代表托管服务不处理访问记录。

点击外部链接后，对方网站、应用商店或服务将按其自身政策处理信息。本政策说明我们自己的处理活动，不替代第三方的隐私说明。

12. 政策更新与联系我们

我们可能因功能、服务提供商或法律要求的变化更新本政策，并修改页面顶部的更新日期。重大变化会按适用要求通过游戏内提示或其他适当方式告知；如需新增同意，会在相关处理开始前取得。政策更新本身不替代所需同意。
